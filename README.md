# 💼 Django Cashflow Project

> **Проект по техническому заданию для компании [IT-Solutions]**

---

## 📋 Описание

Это веб-приложение для управления транзакциями и классификацией доходов/расходов.  
Реализована структура данных `Тип → Категория → Подкатегория`, с валидацией и динамической формой.

---

## 🚀 Установка и запуск проекта

### 🔧 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/django-cashflow.git
cd django-cashflow
```

---

### 🐍 2. Создание и активация виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

---

### 📆 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

> Если файла `requirements.txt` ещё нет:
> ```bash
> pip freeze > requirements.txt
> ```

---

### 🛠 4. Применение миграций и запуск сервера

```bash
python manage.py migrate
python manage.py runserver
```

Открой в браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000)

---

## ✅ Валидация формы `Transaction`

- Категория должна принадлежать выбранному типу
- Подкатегория должна принадлежать выбранной категории

Если валидация нарушена — форма выводит ошибку.

---

## 🔄 AJAX-загрузка категорий/подкатегорий

- Категории загружаются при выборе типа
- Подкатегории загружаются при выборе категории
